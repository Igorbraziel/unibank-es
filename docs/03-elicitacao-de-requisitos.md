# Elicitação de Requisitos — UniBank

Grupo 7 — Ponto e Vírgula

## 1. Stakeholders do UniBank

| Stakeholder | Descrição |
| :--- | :--- |
| Usuários finais | Pessoas com contas em múltiplas instituições financeiras que querem centralizar suas finanças. |
| Instituições financeiras | Fornecem os dados via Open Finance (atores externos). |
| Administradores do sistema | Responsáveis pela manutenção, monitoramento e logs de auditoria. |
| Órgãos reguladores | Regulam o Open Finance e a segurança de dados financeiros. |

## 2. Técnicas de elicitação

| Técnica | Como seria usada |
| :--- | :--- |
| Entrevistas | Usuários finais em potencial (pessoas com contas em múltiplos bancos), para entender dores reais de descentralização financeira; e representantes de instituições financeiras/especialistas em Open Finance, para entender limitações técnicas e regulatórias da integração. |
| Questionários | Uma amostra maior de usuários finais (estudantes, profissionais etc.), para validar quais funcionalidades são mais desejadas (ex.: dashboard, categorização automática, relatórios) e quantos bancos/cartões cada pessoa costuma usar em média. |
| Workshops (JAD) | A própria equipe de desenvolvimento junto com um representante do usuário final e, idealmente, alguém com conhecimento técnico de Open Finance, para alinhar o escopo das integrações, telas do dashboard e regras de categorização. |
| Observação | Observar como usuários reais gerenciam suas finanças hoje: como preenchem planilhas manuais, como alternam entre apps de bancos diferentes, como categorizam gastos (mentalmente, em papel, em apps). |
| Prototipação | Protótipos do fluxo de conexão de contas via Open Finance, do dashboard financeiro consolidado e da tela de categorização de receitas/despesas, funcionalidades centrais e mais sujeitas a ambiguidade de UX. |
| Análise de documentos | Documentação técnica das APIs de Open Finance (especificações do Banco Central), termos de uso/políticas de privacidade de bancos digitais e documentos regulatórios sobre proteção de dados financeiros (LGPD). |
| Estudo de manuais e legislações | Regulamentação do Open Finance Brasil (Banco Central), LGPD, especialmente quanto a dados financeiros sensíveis, e normas de segurança da informação aplicáveis a instituições financeiras. |
| Análise de sistemas similares | Apps de gestão financeira que usam Open Finance no mercado brasileiro, como Organizze, Mobills, Guiabolso (histórico) e recursos nativos de agregação de contas de bancos digitais. |
